# 프롬프트 라이브러리 레지스트리 (진실 원천)

이 파일은 **번호의 유일한 기준**이다. 조립·검증 단계에서 반드시 이 표와 대조한다.
표에 없는 번호·제목·실습 코드는 출력하지 않는다.

- 유형: `교안` = 교안에 실린 프롬프트 / `예시` = 실무 확장용
- 입력: `실습` = 수업 중 수강생이 직접 입력(교시당 3회 고정) / `참고` = 화면으로만 보는 비교·설명용 / `과제` = 수업 후
- 맞춤: `정밀` = 회사·직무 맞춤 필수 / `확장` = 회사 맞춤 권장 / `없음` = 라이브러리 원문 그대로
