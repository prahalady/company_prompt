1. 검색하고 출처 확인하기

클로드 기초교안 기반

교안 실습 1-1 · S1-P01

최근 바뀐 제도·요율·동향처럼 검색이 필요한 주제를, 출처까지 붙여 3줄로 정리받는 프롬프트입니다. 회사 내부 정보는 넣지 말고 공개된 범위로만 물어봅니다.

[주제]에 대해 최근 바뀐 내용을 찾아 3줄로 정리해줘.

각 줄마다 어느 자료에서 나온 내용인지 출처를 함께 표시해줘.

검색으로 확인되지 않은 내용은 넣지 말고, 확실하지 않으면 "확인 필요"라고 써줘.

2. 검색 결과가 부족할 때 덧붙이는 한 줄

클로드 기초교안 기반

교안 실습 1-1 보강 · 13p

검색 결과에 출처가 없거나, 너무 길거나, 추측이 섞였을 때 바로 이어 보내는 짧은 지시문 3종입니다. 상황에 맞는 한 줄만 골라 쓰면 됩니다.

(출처가 없을 때)
각 문장이 어느 자료에서 나왔는지 표시해줘.

(너무 길 때)
핵심 3개만, 한 문장으로 줄여줘.

(추측이 섞였을 때)
검색으로 확인되지 않은 내용은 지워줘.

내가 적지 않은 값은 임의로 채우지 말고 "확인 필요"라고 표시해줘.

[내용]
(여기에 3~4줄로 적기)

── 표가 나오면 이어서 보내기 ──
위 표를 막대 차트로 그려줘.

4. 프로젝트 지침 붙여넣기

클로드 기초교안 기반

교안 실습 1-3 · 52p

프로젝트를 만들 때 지침 칸에 그대로 붙여넣는 기본 지침입니다. 이후 모든 대화에서 말투·형식·금지 규칙이 자동으로 지켜집니다.

[역할] 사무 업무를 돕는 도우미.
[말투] 한국어 존댓말. 쉬운 표현.
[형식] 표를 만들 때는 근거 열을 포함한다.
[금지]
- 내가 주지 않은 값을 지어내지 않는다
- 확실하지 않으면 "확인 필요"로 표시한다
- 실제 회사명·고객명·금액은 다루지 않는다
[수치] 숫자와 날짜는 원문 그대로 옮기고, 계산했으면 계산식을 함께 보여준다.

5. AI가 지금 무엇을 보고 있는지 확인하기

에이전트 시작교안 기반

교안 실습 2-1 · S2-P01

결과가 이상할 때, AI가 지금 참고하는 정보(지침·자료·대화·이번 메시지)를 네 층으로 나눠 확인하는 프롬프트입니다. 프로젝트 안에서 실행합니다.

지금 네가 참고할 수 있는 정보를 아래 네 가지로 나눠서 알려줘.
1) 프로젝트 지침에 적힌 규칙
2) 프로젝트에 올라온 자료
3) 이 대화에서 지금까지 나온 내용
4) 방금 내가 보낸 메시지

각 항목에 실제로 무엇이 들어 있는지 적고, 비어 있으면 "없음"이라고 써줘.
네가 볼 수 없는 것도 함께 알려줘.

6. 지침 보강하기

에이전트 시작교안 기반

교안 실습 2-2 · S2-P02

지금 쓰는 지침을 내 업무에 맞게 점검받는 프롬프트입니다. 전체를 새로 쓰지 않고 빠진 부분·보완 문구만 받는 것이 핵심입니다.

아래는 내 프로젝트 지침이야.
(1교시에서 넣은 지침을 붙여넣기)

내 업무는 [업무 설명]이야.
이 지침에서
1) 빠져 있는 항목
2) 너무 넓어서 지켜지기 어려운 항목
을 짚어 주고, 보완 문구만 따로 제시해줘.
전체를 다시 쓰지는 마.

7. 위임 후보 골라내기

에이전트 시작교안 기반

교안 실습 2-3 · S2-P03

AI가 바로 답을 만들지 않고, 먼저 질문 5개로 내 업무를 파악한 뒤 위임 후보 3개를 위험·확인 지점과 함께 표로 골라주는 2단계 프롬프트입니다.

나는 사무직으로 일하고 있어.
지금 바로 답을 만들지 말고, 내가 반복하는 업무 중에서
AI에게 맡기기 좋은 업무를 고를 수 있도록 질문을 5개만 해줘.
질문은 번호를 붙여 한 번에 보여주고, 내가 답하기 전에는 다음 단계로 넘어가지 마.

── 질문에 답한 뒤 이어서 보내기 ──
내 답변을 바탕으로 위임 후보 3개만 골라줘.
① 적합 이유 ② 위험 ③ 사람 확인 지점을 표로 정리해줘.

17. 검색이 필요한 질문인지 판단하기

클로드 기초추가 제안

검색을 켤지 말지 스스로 고민될 때, 클로드에게 먼저 판단을 시켜보는 실습입니다. 한도를 아끼는 습관을 들이는 데 도움이 됩니다.

아래 세 가지 질문 중 어떤 것이 검색이 꼭 필요하고, 어떤 것이 필요 없는지 구분해줘.
이유도 한 줄씩 붙여줘.

1) 2026년 최저임금이 얼마인지 알려줘.
2) 보고서에서 자주 쓰는 '컨센서스'라는 단어가 무슨 뜻인지 알려줘.
3) 우리 회사 경쟁사인 [회사명]의 최근 신제품 소식을 알려줘.

18. 표를 엑셀 파일로 받고 검증하기

클로드 기초추가 제안

화면에 나온 표를 실제 파일로 내려받아, 원본과 대조하는 순서까지 포함한 구체적인 실습입니다.

아래 내용을 [거래처명 / 품목 / 수량 / 단가 / 합계] 5열 표로 만들어 별도 창에 띄워줘.
합계는 계산식도 함께 보여줘. 내가 적지 않은 값은 "확인 필요"로 표시해줘.

- 대한상사 / 사무용 의자 / 20개 / 45,000원
- 한빛물산 / 모니터 받침대 / 15개 / 12,000원
- 서울테크 / 키보드 / 30개 / (단가 미정)

표가 확인되면, 위 표를 엑셀 파일로 만들어줘.
파일을 받으면 행 수 3개와 합계 값을 원본과 직접 대조해줘.

2단계: (내가 1단계를 승인하면) 표를 바탕으로 보고서 초안 작성
